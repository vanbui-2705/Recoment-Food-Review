# Rec-Food brand specification — v0

- Product name: Rec-Food
- Promise: help Vietnamese users decide what to eat in under 30 seconds.
- Voice: friendly, concise, reassuring, never mechanical.
- Logo: pending official asset. The interface uses an explicit `[logo]` placeholder until supplied.
